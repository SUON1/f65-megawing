Status: **INVALID — DO NOT USE**

The physical MEGA65 chooser displayed `ERROR CODE FF` while `F65R0D.D81` was
selected. This happened before `AUTOBOOT.C65` or `R0D-CALIB` could run, so it
is a carrier, transfer, or chooser-mount failure—not an R0-D program result.

The prior host gate omitted an assertion that the on-image label/ID matched a
physical-accepted profile. The failed image used `F65 R0-D 530K` / `D1`; the
replacement generator requires the retained R0-A/R0-C profile `F65 R0-D` /
`65`, verifies it from raw header bytes, and emits a distinct fresh filename.
This is a compatibility correction to test, not a claim that the label/ID alone
caused the failure. The missing SD-copy hash remains an unresolved alternate
cause.
